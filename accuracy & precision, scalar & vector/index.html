Accuracy, Precision, Scalar & Vector

Mikaila Bautista | 12 - Cramer

Accuracy and precision describe measurements, while scalars and vectors describe physical quantities.

Formulas and Concepts

01Accuracy
Visual guide · Accuracy

Accuracy tells how close a measured value is to an accepted or expected value.

Relative Error = |Measured − Expected| / Expected × 100%
Real-life application: A thermometer reading close to the actual room temperature is accurate.

When to use: Use when comparing a measurement with an accepted or expected value.

02Precision
Visual guide · Precision

Precision tells how closely repeated measurements agree with one another.

Relative Uncertainty = Uncertainty / Measured Quantity × 100%
Real-life application: A digital scale that gives nearly the same reading every time shows high precision.

When to use: Use when judging how consistent repeated measurements are.

03Scalar
Visual guide · Scalar

A scalar has magnitude only and has no direction.

Examples: mass, time, distance, speed, temperature, energy
Real-life application: A car dashboard speedometer gives speed, a scalar, because direction is not included.

When to use: Use when the quantity needs magnitude only, with no direction.

04Vector
Visual guide · Vector

A vector has both magnitude and direction.

Examples: displacement, velocity, acceleration, force, momentum
Real-life application: GPS navigation uses displacement and velocity, which include direction.

When to use: Use when both magnitude and direction matter.

05Vector Components
Visual guide · Vector Components

A vector can be separated into horizontal and vertical components.

Ax = A cos θ | Ay = A sin θ
Real-life application: A ramp force can be split into horizontal and vertical components to simplify analysis.

When to use: Use when a vector is easier to analyze by splitting it into horizontal and vertical parts.

06Resultant Vector
Visual guide · Resultant Vector

The resultant represents the combined effect of vector components.

R = √(Rx² + Ry²) | θ = tan⁻¹(Ry/Rx)
Real-life application: The combined effect of wind and an airplane’s motion can be represented by a resultant vector.

When to use: Use when combining two or more vector components into one net vector.
